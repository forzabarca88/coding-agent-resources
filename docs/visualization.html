Evaluation chart

Every successful evaluation run plotted as a point — total context used against turns — coloured by model. Rendered live from data/eval-results.md.

Read Reading the chart

Each point is one successful run (exit code 0). Total Context Used is the cumulative context consumed during the run; Turns is the number of agent turns taken — the less of each, the better. The dashed lines split the plot into four quadrants at the axis midpoints: the bottom-left (least context, fewest turns) is shaded strongest as the best region, the two adjacent quadrants step down, and the top-right (most context, most turns) is left faintest. The 25 runs with the least context are shown by default (ranked by context alone); use the filters above to change the selection. The search accepts * and ? wildcards (e.g. *qwen*, openrouter/*) to select every matching model at once, and also matches each model's Notes — type Q4 to select every model whose notes mention Q4, for instance. Cloud results are labelled Provider; runs on the local test machines are labelled Local — see the machine specs on Evaluation results. Hover or click a point for its full record.
