Each point is one successful run (exit code 0). Total Context Used is the cumulative context consumed during the run; Turns is the number of agent turns taken — the less of each, the better. The dashed lines split the plot into four quadrants at the axis midpoints: the bottom-left (least context, fewest turns) is shaded strongest as the best region, the two adjacent quadrants step down, and the top-right (most context, most turns) is left faintest. The 25 runs with the least context are shown by default (ranked by context alone); use the filters above to change the selection — an active search or model selection shows all matching runs, so the default 25-run limit no longer applies. The search accepts `*` and `?` wildcards and filters to exactly the runs that match — the pattern is tested against each run's model name and Notes, so `*qwen*` selects every qwen run, `openrouter/*` every provider run, and a note fragment like `Q4` every run whose notes mention Q4. Searching `Q2_K_XL` therefore returns only the runs quantised at Q2_K_XL, not every run of the same model. Cloud results are labelled *Provider*; runs on the local test machines are labelled *Local* — see the machine specs on [Evaluation results](evaluation-results.html).
