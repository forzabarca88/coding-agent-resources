Method Reading the chart

Total Context Used is the cumulative context the agent consumed during the run; Turns is the number of agent turns taken to complete the task. Only runs that exited cleanly (exit code 0) are plotted.

Cloud results are labelled Provider; runs on the local test machines are labelled Local — see the machine specs on Evaluation results. Hover or click any point for the full details of that run.
