Method Reading the chart

Total Context Used is the cumulative context the agent consumed during the run; Turns is the number of agent turns taken to complete the task. Only runs that exited cleanly (exit code 0) are plotted.

Cloud results are labelled Provider; runs on the local test machines are labelled Local — see the machine specs on Evaluation results. Points are coloured by model. Select one or more models from the legend to filter the plot; each selected model keeps its colour, and the runs-to-show limit applies only when every model is selected.

Model labels are drawn beside their point where space allows; when several runs land in the same spot, the group is marked with a +N tag instead. Hover, focus, or click a point for its tooltip — notes first, then context used, turns, duration, and the configured limit.
